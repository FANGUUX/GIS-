# GIS 地理信息系统 🗺️

一个功能完整的基于Web的地理信息系统（GIS）应用程序，提供交互式地图、测量工具和地理数据可视化功能。

## 功能特性 ✨

### 🗺️ 地图功能
- **多种地图图层**
  - OpenStreetMap 标准地图
  - 卫星影像图
  - 地形图
- **交互式操作**
  - 平移和缩放
  - 实时坐标显示
  - 比例尺显示

### 📍 标记和绘图
- **添加标记点**
  - 可拖动标记
  - 自定义标记信息
  - 标记管理（删除功能）
- **测量工具**
  - 距离测量（支持多点测量）
  - 显示公里和米单位
  - 实时测量反馈
- **多边形绘制**
  - 绘制自定义多边形
  - 自动计算面积
  - 支持复杂多边形

### 🔍 搜索和定位
- **地理定位**
  - 获取用户当前位置
  - 显示定位精度
  - 精度圈可视化
- **地址搜索**
  - 地名搜索（使用 Nominatim 服务）
  - 坐标搜索支持
  - 搜索结果标记

### 💡 其他特性
- 响应式设计，支持移动设备
- 实时信息面板
- 一键清除所有标记和绘图
- 现代化UI设计

## 快速开始 🚀

### 在线使用
直接在浏览器中打开 `index.html` 文件即可使用。

### 本地部署
1. 克隆仓库：
```bash
git clone https://github.com/FANGUUX/GIS-.git
cd GIS-
```

2. 使用浏览器打开 `index.html` 或使用本地服务器：
```bash
# 使用 Python
python -m http.server 8000

# 或使用 Node.js
npx http-server
```

3. 在浏览器中访问 `http://localhost:8000`

## 使用指南 📖

### 切换地图图层
在左侧工具面板的"图层控制"部分选择不同的地图图层：
- OpenStreetMap：标准街道地图
- 卫星影像：卫星视图
- 地形图：显示地形高度信息

### 添加标记
1. 点击"📍 添加标记"按钮
2. 标记将添加到当前地图中心
3. 可以拖动标记到任意位置
4. 点击标记查看详细信息
5. 在弹出窗口中可以删除标记

### 测量距离
1. 点击"📏 测量距离"按钮激活测量模式
2. 在地图上点击添加测量点
3. 系统会自动显示累计距离
4. 再次点击按钮结束测量

### 绘制多边形
1. 点击"⬡ 绘制多边形"按钮
2. 在地图上点击添加多边形顶点
3. 系统会自动计算和显示面积
4. 再次点击按钮完成绘制

### 定位功能
1. 点击"📍 定位我的位置"按钮
2. 浏览器会请求位置权限
3. 授权后地图会自动定位到您的位置
4. 显示定位精度圈

### 搜索功能
1. 在搜索框输入地名或坐标
2. 点击"🔍 搜索"按钮或按回车键
3. 地图会自动跳转到搜索结果
4. 支持的格式：
   - 地名：北京、上海、纽约等
   - 坐标：39.9042, 116.4074

### 清除所有
点击"🗑️ 清除所有"按钮可以清除地图上所有的标记、测量线和绘制的多边形。

## 技术栈 🛠️

- **前端框架**: HTML5, CSS3, JavaScript (ES6+)
- **地图库**: [Leaflet.js](https://leafletjs.com/) v1.9.4
- **地图数据源**:
  - OpenStreetMap
  - ArcGIS World Imagery
  - OpenTopoMap
- **地理编码**: Nominatim API
